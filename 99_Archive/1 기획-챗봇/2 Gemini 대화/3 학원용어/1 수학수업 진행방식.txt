#학원 용어

1.채점
- 슬래시(/),세모(△),별표(☆) 표시
- 1차채점(O,/) : 정답을 보고 채점하기
- 2차채점(△,☆) : 1차 채점 후 스스로 고친후 다시 채점하기
- 3차채점 : 2차 채점 후 해설지 참고한뒤,질문하여 해결하고 채점하기
- ☆ 위에 △를 크게 표시

2.숙제 = 학생 스스로 채점(2차 채점까지)
- 별표(☆)문제는 질문할거 정리해서 학원에 오기
- 학원에 와서 오답기록표에 2차채점(△,☆) 결과를 기록하기
- 별표(☆)문제는 질문한 후 해결하기
- 질문한 후 해결한 문제는 ☆ 위에 △를 크게 표시(3차채점)

3.테스트 = 학원에서 조교가 채점 -> 조교가 검사 후 스캔하여 저장
- 1차채점(O,/) : 학생이 풀고 제출하면, 조교가 정답을 보고 채점하기
- 2차채점(△,☆) : 1차 채점 후 학생 스스로 고친후 제출하면, 조교가 다시 채점하기
- 3차채점 : 학생이 해설지 참고한뒤,질문하여 해결하고 제출하면, 조교가 채점하기
- ☆ 위에 △를 크게 표시 

4.오답기록표 = 학생의 틀린문제를 모두 기록한 양식지
- 매일 세로로 기록합니다(날짜,페이지,문제번호)
- 한번에 맞추지 못한 모든 문제(세모,별표)를 모두 기록합니다
- 별표(질문한 문제)는 한번더 풀면 또 틀리는 경우가 많습니다
- 진도를 나가면서 특정 단원이 오답이 많다면, 그 단원이 약한 단원입니다
- 전체 오답개수가 같다면, 별표가 많은 단원이 좀더 약한 단원입니다

5.복테 = 복습테스트 = 매일 제공하는 오답노트 
- 오답기록표에 기록된 문제로 만든 학생별 시험지
- 틀린문제를 하루이상 지나서 푸는 복습 형식
- 힌트없이 푸는 테스트 형식
- 손으로 모든 문제를 쓰는건 시간낭비
- 복습을 안하면 비효율적인 공부
- 눈으로 푸는 경우에 수학은 복습효과 없음

6.틀린이유
- "오답 유형 분류표" 참고하여 "틀린이유" 쓰기
- 목적은 채점 후 학생 스스로 고민을 한번더 하게 하는 습관을 만들기

7.오답유형분류표
- 학생들이 많이 틀리는 이유에 대하여 종류별로 분류한 표
- 학생별로 틀린이유를 작성하는 예시
- 예를들어, "계산실수"라고만 적으면, 
  한달뒤에 "본인"이 봐도 "무슨 이유"로 틀린건지 알지 못하는 상황이 발생
- "구체적으로 작성"해야 본인 약점을 "교정" 가능
- 오답 유형 분류표는 좀더 자세히 유형을 제공함
  1-1,1-2,1-3....은 좀더 구체적으로 쓰는 예시를 제공
- 스스로 "틀린이유"를 쓰면서, "풀이과정"을 머릿속으로 "되새김질" 하게됨
- 수업때 학생이 쓴걸 확인후 피드백을 함

8.테스트
- 진도 나가능 중간에 진행
- 채점 후 피드백(칠판설명,개별첨삭,해설지 제공) 진행
- 테스트 종류
1)복습테스트 = 복테
2)진단평가 = 진단
3)오분테스트 = 5테
4)단원테스트 = 단테
5)단원평가 = 단평
6)내신모의고사 = 내신모의

9.오답노트
- 교재 전체 오답노트
- 누적복습 오답노트
- 교재 진도 전체가 끝나면, 복테(매일 제공하는 오답노트)전체를 제본하여 제공함
- 숙제로 내주고, 수업때 다시한번 전체 복습을 함
- "복테"와 "오답노트"를 다르게 정의함
- "복테"는 매일 오답노트, "오답노트"는 전체 오답노트

10.진단평가
- 교재 전체 누적테스트
- 단원별 중요한 문제를 선별하여 20개~25개 문제를 테스트
- 시간재서 풀고 제출하면 채점
- 1차 커트라인,2차 커트라인이 있어서 추가 과제가 나가기도 함

11.교재검사
는 목차 위에 표시
- 교재가 끝나면 교재검사를 합니다
- 목차 위에 볼펜으로 적힌 숫자는 덜 완료된 페이지입니다
- 미완료시 완료될때까지 여러번 검사합니다

12.점검하기
1)복테 = 복습테스트 = 복습+테스트
- 보고 푼 문제는 하루이상 지나서 풀면 막히는 부분이 있습니다
- 그 부분을 확인하는 연습을 따로 해야 합니다
2)테스트
- 학원에서 배운 단원에 대해서 시험을 보고 있습니다
- 채점은 담당선생님이나 보조선생님이 하고 있습니다
3)오답노트
- 교재 전체를 총복습을 합니다
4)진단평가
-교재 전체를 테스트 합니다
5)교재검사
- 별표나 안 푼문제가 없는지 확인합니다

13.수업사진
- 수업시간에 칠판설명,노트첨삭은 카톡으로 전송
- 집에서 복습할때, 수업사진을 참고하기
- 손으로 직접 써보면서 연습을 하는게 필수
1)보고 따라하기
2)안보고 스스로 해보기
3)혼자 하다가 막힌 부분은 표시하기
4)막힌 부분은 따라하기
5)다시 안보고 해보기

ㄴ)추가 설명
1.숙제에서 틀린문제를 "오답기록표"에 기록하기
- 양식지의 페이지마다 상단에 학생이름,교재가 적혀 있음
- 2열이 한개 세트(1열 : 단원명,페이지 번호/ 2열 : 날짜,문제 번호)
- 양식지의 표 안에 날짜,페이지 번호,문제 번호를 쓰기

2."테스트"가 있으면,테스트를 먼저 풀기
- 테스트는 다풀고, 조교에게 제출후 채점받기
- 채점 후 덜 완료된 문제를 고치고 다시 제출하기
- 완료 후 "틀린이유"를 "오답유형 분류표"를 참고하여 쓰기

3.테스트가 없으면,"복테"를 풀고 채점하고 고치기

- 막히거나 헷갈리는 문제는 별표하고 "질문"하기
- 질문해서 설명 듣고 풀게 되면, 별표 위에 세모 표시하기

4.복테를 모두 풀게 되면,"교재"를 이어서 풀고 채점하고 고치기
- 채점 후 틀린문제를 오답기록표에 기록하기
- 막히거나 헷갈리는 문제는 별표하고 "질문"하기
- 질문해서 설명 듣고 풀게 되면, 별표 위에 세모 표시하기

5.교재가 끝나고 "오답노트"를 받게 되면,
- "교재검사"를 위해서 교재를 학원에 제출하기
- 오답노트를 순서대로 끝까지 풀고 채점하고 고치기
- 틀린 문제 중 안 풀리면, 지난번에 풀이했던 내용 참고하기
- 막히거나 헷갈리는 문제는 별표하고 "질문"하기
- 질문해서 설명 듣고 풀게 되면, 별표 위에 세모 표시하기

6.오답노트가 모두 완료하면,"진단평가"를 쳐야함
- 시간재서 풀고, 제출하기
- 채점 후 커트라인에 따라서 과제가 다름
- 1차 커트라인(70점)/2차 커트라인(50점)
- 1차 커트라인 통과 : 진단평가 오답만 연습장에 풀고 제출하기
- 2차 커트라인 통과 : 오답노트를 다시한번 풀고 제출하기
- 2차 커트라인 불통 : 진단평가 틀린문제와 관련된 과제를 받아서 풀고 제출하기

#학부모

1.숙제할때 확인할 내용
- 오답을 "스스로 고쳐나가기"가 가장 기본적인 태도입니다
- 부족한 부분은 앞부분을 찾아서 참고하기
- 단, 거기서 멈추면 실력이 더이상 올라가기 어렵기 때문에
참고해서 푼 문제는 다시 한번 풀이과정을 "안보고" 푸는 
"복습"을 해야 합니다~

2.학원에서는 여러가지 방식으로 점검하고 있습니다
1)복테(복습+테스트)
보고 푼 문제는 하루이상 지나서 풀면 막히는 부분이 있습니다
그 부분을 확인하는 연습을 따로 해야 합니다
2)테스트
학원에서 배운 단원에 대해서 시험을 보고 있습니다
채점은 담당선생님이나 보조선생님이 하고 있습니다
3)오답노트
교재 전체를 총복습을 합니다
4)진단평가
교재 전체를 테스트 합니다
5)교재검사
별표나 안푼문제가 없는지 확인하기

3.부모님이 도와주실수 있다면,
(채점,해설지,질문)에 대한 자료를 읽어보시고 참고해주시면 됩니다~

학원은 단체수업이다보니, 학생들에게 방법을 알려주고 있지만, 
아무래도 꼼꼼하게 진행되기 어려울때가 있습니다

학습효과가 2배가 될수 있습니다

A2.네 진단평가는 끝나고, 시험지와 함께 부모님께 전달합니다

#조교

1."복테"를 학생이 복테 제출함에 제출하면, 채점 검사 후 
1)미완료(/,☆) -> 복테 보관함에 보관하여 다음시간에 학생에게 제공
2)완료(O,△) -> 채점기록(오답개수/전체개수) 후 세모표시하고, 스캔후 저장하기

2.채점

1)숙제 = 학생 스스로 채점 -> 검사 후 스캔하여 저장
- 슬래시(/),세모(△),별표(☆) 표시
- 1차채점(O,/) : 정답을 보고 채점하기
- 2차채점(△,☆) : 1차 채점 후 스스로 고친후 다시 채점하기
- 3차채점 : 2차 채점 후 해설지 참고한뒤,질문하여 해결하고 채점하기
- ☆ 위에 △를 크게 표시

2)테스트 = 조교가 채점 -> 검사 후 스캔하여 저장
- 슬래시(/),세모(△),별표(☆) 표시
- 1차채점(O,/) : 정답을 보고 채점하기
- 2차채점(△,☆) : 1차 채점 후 스스로 고친후 다시 채점하기
- 3차채점 : 2차 채점 후 해설지 참고한뒤,질문하여 해결하고 채점하기
- ☆ 위에 △를 크게 표시

2.교재가 끝나면 "교재검사" 하기
- 목차 위에 볼펜으로 덜 완료된 페이지를 쓰기
- 숙제 완성도가 부족한 학생은 단원마다 검사하기
- 검사한 날짜를 목차에서 마지막 페이지에 쓰기
- 추가검사 후에 완료된 페이지 위에 슬래시(/) 표시하기
- 모두 완료된 경우에는 "OK"라고 쓰기

3.교재가 끝나면, "오답노트"를 만들기
- 오답기록표에 "끝"이라고 적혀있으면, "오답노트"를 만들어야 함
- 새로운 폴더 만들기
- 폴더 이름은 "날짜" "오답노트" "교재" "학생이름" 순서대로 만들기
예를들어, "260402 오답노트 중1-1 쎈 김철수"

- 오답기록표에서 교재가 시작한 날짜 확인한후
  학생 복테폴더에서 복테 문제와 빠른정답 파일을 복사하기
- 학생마다 교재 전체 복테를 모두 프린트 하여 제본하기
- 날짜 순서대로 정리하기(문제 따로,빠른 정답 따로)
- 첫페이지 상단에 볼펜으로 "오답노트" "시작 날짜" "끝난 날짜"를 쓰기
예를들어, "오답노트 260402~260605"

- 오답노트 전체가 채점완료가 되면, 
 "전체 오답개수/전체 문제개수"를 확인 후 볼펜으로 쓰기
- 오답노트의 링을 제거후 전체스캔하여 저장하기
- 파일명은 "오답노트 폴더명"으로 만들기

4."틀린 이유" 쓰기는 "오답유형 분류표"를 참고하여 쓰는지 검사
- "오답 유형 분류표"는 교재 앞쪽에 붙여주기
- "오답 유형 분류표"는 학생별로 틀린이유를 작성하는 예시입니다

1)틀린이유
- "오답 유형 분류표" 참고하여 "틀린이유" 쓰기
- 목적은 채점 후 학생 스스로 고민을 한번더 하게 하는 습관을 만들기

2)오답유형분류표
- 학생들이 많이 틀리는 이유에 대하여 종류별로 분류한 표
- 학생별로 틀린이유를 작성하는 예시
- 예를들어, "계산실수"라고만 적으면, 
  한달뒤에 "본인"이 봐도 "무슨 이유"로 틀린건지 알지 못하는 상황이 발생
- "구체적으로 작성"해야 본인 약점을 "교정" 가능
- 오답 유형 분류표는 좀더 자세히 유형을 제공함
  1-1,1-2,1-3....은 좀더 구체적으로 쓰는 예시를 제공
- 스스로 "틀린이유"를 쓰면서, "풀이과정"을 머릿속으로 "되새김질" 하게됨
- 수업때 학생이 쓴걸 확인후 피드백을 함
