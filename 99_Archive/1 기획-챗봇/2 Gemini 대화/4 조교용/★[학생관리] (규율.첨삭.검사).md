학생관리(규율/첨삭/검사)

a : 규율
a-1> 몰라요~하면서 그냥 물어봐요
a-2> 쓰기 귀찮아요
a-3> 시키지 않으면 안해요
a-4> 글씨체가 삐뚤삐뚤 

b : 첨삭
b-1> 실수를 많이 해요 
b-2> 이해보다 암기하고 넘어가려고 해요 
b-3> 노트정리를 너무 예쁘게 하려고 해요

c : 검사
c-1> 물어보지 않으면 질문을 안해요
c-2> 숙제를 밀리는 경우가 있어요
c-3> 졸리면,자세가 흐트러져요

규율 : 습관을 잡아야 하는 학생 -> 학생설명에 특이사항을 기록하기
첨삭 : 몰라서, 못하는 학생 -> 지우개 사용 줄이기
검사 : 아는데, 안하는 학생 -> 채점 V 표시 하기
