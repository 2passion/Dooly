***************< 추가 업무 >*****************
(1)주변정리

1>학원물품 정리 
 ➀목적 : 원래위치에 보관하여 필요할 때 바로 찾을 수 있게 하기
 ➁방법 : 퇴근전에 각위치별로 확인 후 배치하기
 - 필기구 : 1세트(빨간펜 1개/검은펜 1개)=> 데스크(1세트) 통(1세트) 자습실앞(1세트) 자습실뒤(3세트)
 - 스테플러 : 데스크(1개) 자습실뒤(1개)
 - 제침기 : 데스크(2개)
 - 타이머 : 데스크(5개)
 - 제본기 : 작업 후 남은 부스러기 제거하기

(2) 포스트잇 : 작업당일 지시사항
 ➀목적 : 매일 추가로 해야할 내용을 요약하여 담당자에게 전달
 ➁방법 : PC근처에 있는 포스트잇을 읽어보고 질문한뒤 작업하기


(3) 작업자료 : 최근 한달간 담당자에게 필요한 파일을 공유하기
 - 조교할일 
 ➀목적 : 당일작업할 담당자에게 필요한 파일을 공유하기
 ➁방법 : 근무당일 출근하면 작업할 내용을 질문한뒤 작업하기

(4) 연습노트 : 필요할 때 바로 제공할 수 있도록 미리 5권 준비해두기
 ➀목적 : 필요한 학생에게 제공할 수 있도록 준비해두기
 ➁방법 : 근무당일 출근하면 확인 후 양식지에 프린트 후 제본하기
