# 현재 발견된 중복

## 중복 A : 조교 매뉴얼

현재 아래 내용이 여러 번 반복됨

* 신규 조교 가이드
* 인수인계
* 복테
* 오답기록표
* 연습장
* 제본기
* 복사기
* 이면지
* A4박스
* 비품관리

실제로는

```text
조교 업무 종합 매뉴얼
```

1개로 통합 가능

# 구현 순서 (중요)

지금은 7번까지 한 번에 만들면 안 됩니다.

순서 추천:

### Phase 1

문서 정리

```text
SOP
예외상황
질문사례집
```

---

### Phase 2

조교 교육 챗봇

Level 1

```text
질문 답변
매뉴얼 검색
```

---

### Phase 3

조교 관리 시스템

Level 2

```text
업무 지시
업무 보고
진행 추적
```

---

### Phase 4

Claude Code 연동

```text
Obsidian
GitHub
자동 문서 관리
```

---

### Phase 5

KingMath OS

(나중)

```text
학원 전체 운영
```

---

현재 단계에서 구현 계획서를 만든다면 
**"Level 1 조교 챗봇 + Level 2 조교 관리 시스템"까지만 범위를 제한**하는 것이 
가장 현실적입니다.

그렇게 하면 문서도 약 80% 줄어들고, 검증과 수정 작업도 훨씬 쉬워집니다.
