모두 올린후 챗봇에 반영할 것을 한번에 검토해줘

좋아.

그렇게 하는 게 훨씬 효율적이야.

지금 단계에서는 내가 중간중간 검토하는 것보다,

```text
조교 업무 자료 #1
조교 업무 자료 #2
조교 업무 자료 #3
...
조교 업무 자료 #N
```

전부 업로드한 후에 한 번에 분석하는 것이 좋다.

---

그때 내가 아래 관점으로 검토해줄 수 있어.

### 1. 챗봇 반영 여부

각 자료를

```text
필수 반영
권장 반영
참고용
제외
```

로 분류

예시

```text
결석 처리 규정
→ 필수 반영

학원 철학
→ 권장 반영

직원 회식 사진
→ 제외
```

---

### 2. 챗봇 기능 분류

예시

```text
FAQ

업무 절차

상황별 대응

체크리스트

공지사항

보고 양식
```

등으로 분류

---

### 3. 시스템 프롬프트 반영

예시

```text
조교는 학생에게 직접 약속하지 않는다.

학부모 민원은 원장에게 보고한다.

결석 연락은 즉시 기록한다.
```

같은 규칙 추출

---

### 4. 지식베이스(DB) 분리

모든 내용을 프롬프트에 넣는 것이 아니라

```text
시스템 프롬프트

+

FAQ

+

업무 매뉴얼

+

상황별 대응집
```

으로 분리

---

### 5. 챗봇 MVP 범위 결정

초기 버전(예: Dooly Assistant v1.0)에 넣을 기능

```text
출결 문의
채점 규정
숙제 확인
결석 처리
학부모 응대
```

---

후속 버전(v2.0 이상)으로 미룰 기능

```text
자동 보고서
업무 통계
AI 업무 분석
```

---

### 6. 문서 체계까지 설계

업로드가 끝나면

```text
Dooly_Assistant/

├── command/
├── dev/
├── log/
├── user/
├── prompt/
├── faq/
├── knowledge/
└── archive/
```

형태로 어떤 자료를 어느 폴더에 넣을지까지 정리 가능

[Claude Project 지침(Instructions) 설정값]

# 역할 정의
당신은 '킹수학전문학원'의 조교 관리 및 업무 지원 AI입니다. 조교들이 업무 중 궁금한 점을 물어보면, 원장님이 정해둔 [업무 루틴]과 [운영 매뉴얼]에 근거하여 정확하고 친절하게 답변합니다.

# 핵심 운영 원칙
1. 조교의 업무 누락 방지를 최우선으로 합니다.
2. 항상 정확하고 간결하게 답변하며, 필요 시 업무 체크리스트를 상기시켜 줍니다.
3. 원장님의 철칙(예: 시간 엄수, 자료 정리 규칙)을 항상 준수합니다.

# 주요 업무 지식 (Knowledge Base)
- 업무 루틴: 등원 시 준비, 테스트 생성, 복테 PDF 관리, 오답기록표 관리, 퇴근 전 정리.
- 문제 해결: 자료 출력 오류, 학생 질문 대응법, 복습 테스트 진행 방식.

# 답변 가이드라인
1. 질문이 들어오면 먼저 [업무 루틴]에 비추어 현재 조교가 무엇을 해야 하는지 확인합니다.
2. 조교의 질문이 매뉴얼에 명시된 내용이라면 해당 내용을 인용하여 안내합니다.
3. 상황이 모호할 경우, "원장님께 확인이 필요한 사항입니다"라고 명확히 안내합니다.

# 시스템 동작 루틴 (조교 요청 시)
- 조교가 "오늘 할 일 뭐야?"라고 물으면: 현재 시간과 요일을 고려하여 [등원 전 - 등원 중 - 퇴근 전] 업무 루틴 중 현재 수행해야 할 항목을 우선 제시합니다.
- 조교가 "복테 어떻게 만들어?"라고 물으면: [King Test Maker] 사용법을 단계별로 안내합니다.

신규 조교님이 첫 출근부터 퇴근까지 헤매지 않고 업무를 완벽하게 수행할 수 있도록, 기존에 확인한 모든 매뉴얼과 이번에 새로 주신 '조교 업무 타임라인'을 결합하여 최종 [신규 조교 업무 수행 표준 매뉴얼]로 정리했습니다.

이 매뉴얼을 출력해서 조교 업무 공간에 비치해주시면, 신규 조교님이 사수 없이도 스스로 업무를 점검하며 처리할 수 있을 것입니다.

📘 [킹수학] 신규 조교 업무 수행 표준 매뉴얼
1. 근무 시작 및 환경 설정
인터넷 연결: 연결이 잠시 끊기면 자동 재연결을 기다리십시오. (연결 전에는 공유폴더/프린트 사용 불가)

비품 관리: A4 용지, 제본 링, 연습장(5권 유지) 등 소모품은 재고가 20~30% 남았을 때 미리 원장님께 보고합니다.

화장실 에티켓: 사용 후 반드시 문 닫고, 불 끄기.

2. 등원 시 루틴 (입장 후 순서)

3. 복습 테스트(복테) 제작 및 관리
파일 수정: 학생별 폴더에 오답기록표/복테 파일을 복사하고 날짜를 당일 기준으로 수정합니다. (복테 내 날짜도 꼭 확인!)

오답노트 제본: 오답기록표에 "끝" 표시 시, 전체 오답을 모아 제본.

첫 페이지 상단에 "만든날짜" + "오답노트" 기입.

양에 따라 링 선택: 소형(12mm)/대형(20mm).

학생 있으면 즉시 전달, 없으면 [복테 보관함]에 보관.

4. 하원/제출물 처리 루틴
채점: 1차(○/), 2차(△,★), 3차(도움 후 △) 확인.

맞힌 개수/전체 문항수를 점수란에 기입 (예: -3/4).

스캔/저장:

완료된 복테: 스캔 후 학생 폴더 저장 → 문제지는 폐기(A4 박스에 모으기), 정답지(뒷면 백지)는 이면지 보관함으로.

미완료 복테: 다음 등원 시 바로 꺼낼 수 있게 [복테 보관함]에 보관.

파일 보관: 최종 복사본을 공유폴더 > ★복테 > OO부 > OOO(학생이름) 및 바탕화면 날짜 폴더에 저장.

5. 퇴근 전 마무리 (업무 종료 30분 전)

정리: 인쇄물을 오답기록표와 함께 [복테 보관함]의 해당 학년/반 섹션에 배치.

최종 백업: 바탕화면 날짜_L 폴더를 워드(파일)로 복사 후, ★★★작업완료 공유폴더에 최종 복사(Ctrl+V).

기기 점검: 제본기 종이 찌꺼기함 비우기, 복사기 ADF 확인.

기존 조교님이 신규 조교님께 체계적으로 업무를 인수인계할 수 있도록 '조교 업무 인수인계 표준 가이드(3단계 프로세스)'를 정리해 드립니다.

이 매뉴얼을 기존 조교님께 전달해주시면, 교육 시 시행착오를 줄이고 업무를 표준화하는 데 큰 도움이 될 것입니다.

📘 [킹수학] 조교 업무 인수인계 표준 가이드
기존 조교님은 신규 조교님께 아래 3단계 프로세스에 따라 업무를 차근차근 전수해 주시기 바랍니다.

💡 인수인계 기본 원칙
표준화: 개인적인 업무 스타일보다는 원장님께서 정해주신 [킹수학 업무 매뉴얼]을 기준으로 교육합니다.

시범 교육: 1단계(보여주기) → 2단계(옆에서 보기) → 3단계(혼자 해보기/교정) 순으로 진행합니다.

[3단계 인수인계 프로세스]
1단계: 모델링 (기존 조교 시범)
내용: 기존 조교님(예: 이니셜 A)의 업무 처리 방식을 직접 보여줍니다.

방법: 이니셜 A를 기준으로 작성된 '전달사항'과 '자료 제작 과정'을 신규 조교님께 보여주며 흐름을 설명합니다.

2단계: 코칭 (신규 조교 실습 및 조언)
내용: 신규 조교님(예: 이니셜 B)이 직접 업무를 수행합니다.

방법: 이니셜 B를 기준으로 전달사항을 작성하고 자료를 만들게 합니다. 기존 조교님은 옆에서 과정을 지켜보며 실수하는 부분을 바로잡아 주고 조언합니다.

3단계: 영역별 심화 인수인계 (업무 항목별)
아래 3가지 항목에 대해 1~2단계 방식을 반복하여 숙달시킵니다.

a. 복테 및 오답기록표 관리

학생 제출함 비우기, 오답기록표 확인, 복테 제작 및 파일 날짜 수정, 복테 보관함 분류(학년/반/섹션파일 활용) 교육.

b. 전달사항 및 연습장 제작

'조교할일' 텍스트 확인 및 수행, 이니셜 부여, 연습장 보관함(5권 유지) 확인 및 제본기 사용 교육(12mm 링 활용).

c. 복사기 및 비품 관리

복사기 스캔(ADF/수동)/복사(양면 설정) 방법, 제본기 펀칭(20장 기준/잔여물 비우기) 교육, A4용지 박스 재활용 교육.

💡 기존 조교님을 위한 업무 전달 팁
질문의 생활화: 신규 조교님이 모르는 것이 있다면, "나중에 다시 물어봐"라고 하기보다 "지금 같이 다시 확인하자"며 원장님께 질문하는 법을 먼저 알려주세요.

매뉴얼 기록: 인수인계 중 신규 조교님이 자주 헷갈려 하는 포인트는 '업무 매뉴얼' 파일에 추가 기록하도록 지도해 주세요.

환경 교육: 복사기 종이 걸림 방지나 제본기 청소처럼 기기 관리 부분은 기기 수명과 직결되므로 강조해서 교육해 주세요.

```text
- 신규 조교가 직접 수행
- 기존 조교가 옆에서 교정

3단계 : 독립 수행
- 신규 조교 혼자 수행
- 결과 검토 및 피드백
```

특히 이 부분은 매우 중요해.

```text
매뉴얼에 기록한다
```

왜 중요하냐면,

대부분 학원은

```text

```

상태로 끝나.

```text
지식도 같이 퇴사
```

함.

```text
사람
↓
매뉴얼
↓
챗봇
```

구조야.

즉,

```text
A가 발견한 노하우

↓

매뉴얼 기록

↓

챗봇 반영

↓

신규 조교 교육
```

이 가능해짐.

```text
DOOLY Assistant

├─ 01_업무매뉴얼
│
├─ 02_FAQ
│
├─ 03_업무체크리스트
│
├─ 04_상황별대응
│
├─ 05_교육매뉴얼
│
├─ 06_인수인계매뉴얼
│
```

형태로 갈 가능성이 높아.

A. 신규 조교 첫 출근 가이드
필수 준비: 성범죄 경력 조회(본인 인증) 완료.

업무용 이니셜: 본인의 업무 명칭(이니셜)을 원장님께 확인받으십시오.

업무 숙지: '풀어볼거(이니셜)' 자료를 순서대로 풀며 업무 흐름을 익히십시오.

질문 원칙: 처음 하거나 이해가 안 되는 업무는 반드시 원장님께 질문 후 진행하십시오.

데이터 기록: 업무 중 잊기 쉬운 내용은 '업무 매뉴얼' 파일에 즉시 기록하십시오.

B. 기존 조교의 업무 인수인계 가이드 (3단계 프로세스)
기존 조교는 신규 조교에게 표준 매뉴얼에 근거하여 아래 단계를 준수하여 교육합니다.

1단계 (모델링): 기존 조교의 업무 처리 방식(전달사항 및 자료 제작 등)을 신규 조교에게 직접 시범을 보이며 설명합니다.

2단계 (코칭): 신규 조교가 직접 업무를 수행하게 하고, 옆에서 지켜보며 실수를 바로잡고 조언합니다.

3단계 (영역별 실무 전수): 아래 항목별로 반복 숙달시킵니다.

a. 복테/오답기록표: 수거, 제작, 분류 및 보관함 관리.

b. 전달사항/연습장: '조교할일' 수행 및 연습장(5권) 제작·제본.

c. 복사기/비품: 스캔, 복사, 용지/제본링 관리 및 기기 정비(찌꺼기 제거).

C. 조교 업무 루틴 가이드
1. 매일 수행 루틴
출근 직후:

복테 제출함 확인.

'조교할일(이니셜)' 확인 및 업무 시작(이해 안 되면 즉시 질문).

연습장 보관함(5권) 및 이면지 보관함 정리.

업무 중 (수시):

복사기/제본기 사용 후 반드시 폐지/찌꺼기 정리.

A4 용지 박스는 훼손 없이 폐기물 보관용으로 활용.

PC 사용 시 단축키 활용(한글/PDF) 및 공유폴더 규칙 준수.

퇴근 30분 전:

학생별 복테 프린트 → PC 저장 → '작업완료' 폴더 저장.

바탕화면 날짜 폴더 자료를 학생별 폴더에 저장.

퇴근 직전:

주변 정리: [책상 위 → 의자 위 → 바닥] 순서로 청소.

필기구 원위치(필기구 배치 기준 준수).

PC 및 모니터 전원 끄기.

💡 [핵심 부록] 주요 비품 배치 및 기준
연습장: 상시 5권 유지 (50매 양식 사용).

제본 링: 소형(12mm - 연습장/모의고사), 대형(20mm - 오답노트/기출).

비품 보고: 재고 20~30% 남았을 때 미리 원장님께 보고.

복사기: 양면 출력이 원칙이며, 구겨진 종이는 반드시 수동 스캔.

원장님께서 정리해주신 매뉴얼에 따라 **복습 테스트(복테)**와 **오답기록표**의 운영 방식을 알기 쉽게 정리해 드립니다. 신규 조교님이 이 내용을 숙지하면 업무 흐름을 빠르게 파악할 수 있습니다.
### 1. 오답기록표 작성 및 관리 (학생 등원/하원 시)
오답기록표는 학생이 스스로 본인의 학습 상황을 점검하는 핵심 양식지입니다.
 * **작성 원칙:** 학생은 학원에 오면 본인의 오답기록표를 찾아, **오늘 학습 중 틀린 모든 문제**를 기록합니다.
 * **기록 항목:** 날짜, 페이지, 문제 번호를 세로로 기록합니다.
 * **별표(★) 표시:** 스스로 고민하고 질문이 필요한 문제는 **문제 번호 뒤에 별표(★)**를 반드시 표시합니다.
 * **제출:** 하원 시에는 반드시 학원에 제출하고 귀가합니다 (절대 개별 소지 금지).
 * **조교의 역할:** 학생이 하원한 후, 이 오답기록표를 보고 해당 학생만의 **'복테(복습 테스트)'**를 생성하여 보관합니다.
### 2. 복습 테스트(복테) 운영 (등원 시)
복테는 '틀렸던 문제를 하루 이상 지난 뒤 힌트 없이 다시 푸는' 누적 복습용 미니 테스트입니다.
 * **제공:** 학생이 등원하면, 조교는 보관함에서 해당 학생의 오답기록표와 함께 오늘 풀 복테를 제공합니다.
 * **풀이 및 채점:**
   * 학생은 복테를 풀고 조교에게 제출합니다.
   * 조교는 정답지를 보고 **1차 채점(O, /)**을 합니다.
   * 학생이 오답을 스스로 고치고 다시 제출하면 조교가 **2차 채점(△, ★)**을 진행합니다.
   * 3차 채점(도움을 받아 해결) 시, 별표(★) 위에 큰 세모(△)를 표시합니다.
 * **완료 및 저장:** 모든 별표 문제가 큰 세모(△)로 완벽히 해결되어야 '완료'입니다. 완료된 복테는 점수 칸에 세모 표시를 하고 **스캔 후 저장**합니다.
 * **미완료 시:** 해결되지 않은 복테는 다음 시간에 다시 풀 수 있도록 **'복테 보관함'**에 넣어둡니다.
### 💡 요약: 업무 순서
 1. **등원 시:** 학생에게 [오답기록표 + 복테] 제공.
 2. **수업 중:** 학생이 오답 해결 및 조교 채점(1차, 2차, 3차) 수행.
 3. **하원 시:** 학생이 오답기록표 및 복테 제출.
 4. **하원 후:** 조교는 제출된 오답기록표를 토대로 다음 시간용 복테 제작 및 파일 정리.
**신규 조교를 위한 꿀팁:**
"복테는 학생이 **지난번에 틀렸던 문제를 완벽히 자기 것으로 만드는 과정**입니다. 따라서 학생이 단순히 답만 적어내는 것이 아니라, 스스로 풀이 과정을 충분히 고민하고 있는지 지켜봐 주는 것이 조교 업무의 핵심입니다!"
이 내용 중 실제 업무 수행 시 더 자세히 알고 싶은 부분(예: 오답기록표에 '끝'이라고 적힌 경우의 처리 등)이 있으신가요?

### ⚙️ 제본기 및 링 사이즈 활용 매뉴얼
조교님들은 제본 작업 시 아래 기준을 반드시 준수하여 깔끔한 결과물을 제작해 주세요.
#### 1. 제본기 사용 수칙
 * **작업 단위:** 한 번에 **최대 20장**씩 나누어 펀칭하십시오. (무리하게 많은 양을 넣으면 제본기 틈에 종이가 걸려 작업이 불가능합니다.)
 * **정렬 방식:** 펀치 구멍의 위치를 일정하게 맞추기 위해, **종이를 좌측 끝에 완전히 붙여서** 삽입 후 작업합니다.
#### 2. 제본 링 사이즈 선택 기준 (내용물 양에 따라)
제작하는 자료의 두께에 맞춰 적절한 링을 선택합니다.
| 구분 | 링 사이즈 | 적용 예시 |
|---|---|---|
| **소형** | **12mm** | 연습장, 내신모의 10회분 등 **양이 적은 자료** |
| **대형** | **20mm** | 오답노트(교재 전체), 기출 20개 학교 등 **양이 많은 자료** |
이로써 조교님의 제본 실무까지 완벽한 가이드라인이 구축되었습니다. 이 내용들은 신규 조교님들이 업무를 처음 배울 때 실수하기 쉬운 부분들을 정확히 짚어주므로, 큰 도움이 될 것입니다.
혹시 이 외에도 **'이것만큼은 꼭 강조하고 싶다'** 하시는 실무 팁이 있으신가요? 말씀해주시면 매뉴얼을 더욱 견고하게 다듬어 두겠습니다.

### ⚠️ 제본기 사용 후 필수 관리 수칙
제본기를 사용한 뒤에는 **'종이 찌꺼기(펀치 내용물)'**를 반드시 비워주어야 합니다. 이를 잊으면 기기 내부에 잔여물이 쌓여 다음 작업 시 구멍이 제대로 뚫리지 않거나, 기기 고장의 원인이 될 수 있습니다.
 * **관리 루틴:** 제본 작업 직후, 하단(또는 측면)의 **종이 찌꺼기 보관함(폐지통)**을 확인하여 즉시 비워주세요.
 * **주의 사항:** 제본기를 사용할 때마다 "작업 종료 = 보관함 비우기"를 하나의 세트 업무로 습관화해야 합니다.
**[신규 조교를 위한 업무 루틴 체크리스트 업데이트]**
 1. **준비:** 제본기 찌꺼기함 비어 있는지 확인 (깨끗하게 시작)
 2. **펀칭:** 한 번에 20장씩, 왼쪽 정렬 후 구멍 뚫기
 3. **제본:** 적절한 링(소형 12mm / 대형 20mm) 선택 후 제본
 4. **마무리:** **사용 직후 종이 찌꺼기함 비우기 (필수!)**
이 내용까지 포함하여 조교님들께 전달하면, 학원 비품 관리까지 완벽하게 이루어질 것 같습니다. 또 현장에서 발생할 수 있는 소소하지만 중요한 주의사항이 있으실까요? 무엇이든 말씀해주시면 매뉴얼을 더욱 촘촘하게 완성하겠습니다.

### 📥 학생 제출함 관리 매뉴얼 (조교 업무 루틴)
조교님은 매일 학생의 하원 직후, **[학생 제출함]**을 비우고 다음 등원 준비를 완료해야 합니다.
#### 1. 자료 수거 및 구분
 * **학생 제출함 내용물:** 당일 작성한 **'오답기록표'** + 당일 풀고 채점한 **'복습 테스트(복테)'**
 * **업무 구분:**
   1. **오답기록표:** 챙겨서 해당 학생의 **다음 등원용 복테를 제작**합니다.
   2. **복습 테스트(복테):** 채점/완료 여부를 확인하여 아래 단계에 따라 처리합니다.
#### 2. 복습 테스트(복테) 처리 단계
 * **[완료된 복테 (O, △ 표시)]:**
   * 점수 기록 (예: 맞은 개수/전체 문제 개수).
   * 스캔하여 해당 학생 폴더에 **저장**.
 * **[덜 완료된 복테 (/, ★ 표시)]:**
   * 다음 시간에 학생이 다시 풀 수 있도록 **'복테 보관함'**에 보관.
#### 3. 차기 학습 준비
 * 제출된 오답기록표를 보고 학생별 맞춤형 복테를 새로 제작하여 보관합니다. (다음 등원 시 학생에게 즉시 제공)
### 💡 조교 업무 Tip
 * **제출함 비우기 원칙:** "학생이 하원하면 제출함은 반드시 비운다!"를 원칙으로 합니다. 다음 날 등원한 학생이 자기 자료가 준비되어 있지 않아 당황하는 일이 없도록 합니다.
 * **복테 보관함 정리:** 보관함에 들어있는 복테들은 언제든 학생이 등원하면 바로 꺼내줄 수 있도록 **학생 이름순 또는 등원 시간순**으로 정돈해두면 좋습니다.
이 루틴은 **[오답기록표 챙기기 → 연습장 보관함 확인(5권 유지) → 복테 제작 → 복테 보관함 정리]**로 이어지는 조교 업무의 핵심 흐름입니다. 이 흐름을 신규 조교님께 교육하시면 학원 운영이 훨씬 체계적으로 변할 것입니다!

# Dooly 챗봇 관점에서 중요한 변화

기존에는

```text
조교 업무 챗봇
=
복테 챗봇
```

에 가까웠음.

지금은

```text
조교 업무 챗봇
=
학원 운영 지원 챗봇
```

으로 범위가 넓어짐.

---

예를 들어

조교 질문

```text
연습장이 없어요
```

답변

```text
연습장 보관함을 확인하세요.

보관함에는 항상 5권이 유지되어야 합니다.

5권 미만이라면
양식_연습노트_50매.pdf를 출력한 후
12mm 링으로 제본하여 부족한 수량만큼 채워주세요.
```

---

조교 질문

```text
학생이 연습장을 안 가져왔어요
```

답변

```text
복테 제출함 아래의 이면지 보관함을 안내해 주세요.

학생은 보관함의 이면지를 자유롭게 사용하여
문제 풀이를 진행할 수 있습니다.
```

```text

```

```text
□ 필기구 원위치
□ 제본기 찌꺼기함 비우기

```

다음 단계에서는 새로운 매뉴얼보다 오히려 아래 자료가 더 가치가 높아.

```text
실제 조교 질문

"복테를 잘못 저장했어요"

"학생 폴더가 안 보여요"

"오답기록표를 잃어버렸어요"

"학생이 복테를 안 냈어요"

"복사기 종이가 걸렸어요"

"제본기가 구멍을 안 뚫어요"
```

이런 실제 질문 50~100개가 모이면 Dooly 조교 챗봇의 FAQ 데이터베이스가 빠르게 완성될 거야.

현재까지 올라온 자료만으로도 **조교용 챗봇 1차 버전(MVP)** 을 만들 수 있는 수준에 거의 도달했다고 판단돼.

--------------------------
원장님, **복테 보관함의 체계적인 배치 및 섹션파일 활용 방식**까지 모두 확인 및 숙지했습니다. 신규 조교님이 학생의 자료를 찾을 때 혼선이 없도록 업무 매뉴얼에 반영하겠습니다.
### 📂 복습 테스트(복테) 보관함 운영 매뉴얼
복테 보관함은 **학년별/반별**로 구분되어 있으며, 조교님은 아래 배치 규칙을 엄격히 준수하여 자료를 보관해야 합니다.
#### 1. 보관함 배치 순서
 * **[X존 - 고등학생]** (위에서부터 아래로): **고3 → 고2 → 고1**
 * **[Y존 - 초·중학생]** (위에서부터 아래로): **초등 전체 → 중3 → 중2 → 중1**
#### 2. 반별 및 섹션파일 구성
학년별 칸 안에는 **A반, B반**을 구분하는 섹션파일(구분 파일)이 각각 존재합니다. 이 파일을 활용하여 자료를 분리 보관합니다.
 * **섹션파일 구성 (하나의 파일 내 3구역 중 2구역 활용):**
   * **앞부분:** 복습 테스트(복테), 프린트물 보관
   * **뒷부분:** 오답 기록표 보관
### 💡 조교 업무 시 주의사항
 * **자료 찾기:** 학생이 등원하면, 먼저 해당 학생의 **[학년(X/Y존)] → [반(A/B)]**을 확인한 후 보관함을 찾으세요.
 * **자료 보관:** 정리 시 반드시 **[앞부분/뒷부분]** 위치를 구분하여, 오답기록표가 섞이지 않도록 주의합니다.
 * **업무 루틴:** 등원한 학생의 자료를 꺼내줄 때, 보관함 내의 섹션파일 위치가 올바른지 수시로 확인하여 항상 정돈된 상태를 유지하세요.
이로써 학생의 등원부터 하원, 자료 정리, 비품 관리(제본기, 연습장)까지 **킹수학의 모든 운영 시스템이 조교용 가이드라인으로 완성**되었습니다.
이제 신규 조교님이 이 매뉴얼을 활용하면 업무 적응 속도가 훨씬 빨라질 것입니다. 원장님, 혹시 조교님 교육을 위해 **위의 내용들을 정리해서 신규 조교용 '업무 수행 체크리스트' 형태로 깔끔하게 문서화**해 드릴까요? 필요하시면 언제든 말씀해 주세요.

---------------------
이 자료는 단순히 "보관 위치 설명"이 아니라, Dooly 조교 챗봇에서 매우 중요한 **물리적 위치(Location Knowledge)** 데이터야.


원장님, **복사기(스캔 및 복사) 활용 매뉴얼**까지 조교 업무 매뉴얼에 추가하였습니다. 특히 복사기의 경우, 무리한 ADF 사용으로 인한 용지 걸림 방지와 효율적인 출력 설정이 중요하므로 이 부분을 조교님들이 숙지하도록 하겠습니다.
### 🖨️ 복사기 및 스캔 활용 매뉴얼
조교는 학습 자료의 효율적인 디지털화와 출력을 위해 복사기 사용법을 정확히 익혀야 합니다.
#### 1. 스캔 활용 (ADF vs 수동 스캔)
 * **ADF(자동 원고 급지 장치) 사용:** 많은 양의 깨끗한 종이를 한 번에 스캔할 때 편리합니다.
 * **수동 스캔(평판 사용):** 다음의 경우 반드시 ADF를 사용하지 말고, **수동으로 한 페이지씩** 스캔하십시오.
   * 종이가 얇거나 많이 구겨져서 걸릴 위험이 클 때.
   * 종이 상태가 좋지 않아 자동 급지가 어려운 경우.
#### 2. 복사 설정 (양면 출력 원칙)
학원 복사기는 **'양면 출력'을 원칙**으로 하므로, 복사기 터치 화면에서 아래 설정을 기본으로 사용합니다.
| 복사 설정 | 기능 설명 | 사용 빈도 |
|---|---|---|
| **단면 → 단면** | 단면 복사 → 단면 출력 | 보조 |
| **단면 → 양면** | 단면 복사 → 양면 출력 | 보조 |
| **양면 → 단면** | 양면 복사 → 단면 출력 | 보조 |
| **양면 → 양면** | **양면 복사 → 양면 출력** | **주로 사용(원칙)** |
### 💡 조교 실무 주의사항
 * **복사기 관리:** "종이가 걸릴 것 같으면 무리하게 ADF에 넣지 말고 수동으로 하라"는 지침을 반드시 준수하여 기기 고장을 예방합니다.
 * **출력 원칙:** 모든 학습 자료 출력은 기본적으로 **양면 출력**을 설정하여 자원을 효율적으로 관리합니다.
이로써 **[학습 자료 관리 풀세트]**에 **[복사기/스캔 매뉴얼]**까지 추가되어 완벽한 매뉴얼 체계가 잡혔습니다. 이제 이 내용들을 조교님들이 업무 중 헷갈릴 때마다 챗봇에게 물어보면, 원장님의 운영 방침대로 정확하게 처리할 수 있습니다.
추가로 더 상세한 설명이 필요한 부분이나, 원장님께서 특별히 당부하고 싶은 복사기 관련 에티켓이 있다면 말씀해 주세요!

### 📦 소모품 관리 및 재고 보고 매뉴얼
조교는 복사기 및 제본기 사용 시 비품의 잔량을 항상 예의주시해야 합니다.
#### 1. 비치 장소 확인
 * **A4 용지:** 복사기 근처에 박스 단위로 비치.
 * **제본 링:** 제본기 근처에 사이즈별로 비치.
#### 2. 재고 관리의 핵심 원칙: "미리 알리기(Pre-warning)"
 * **보고 시점:** 재고가 완전히 소진되기 전, **추가 주문이 필요한 시점(약 20~30% 잔량 남았을 때)**에 미리 원장이나 강사에게 전달합니다.
 * **보고 내용:** "현재 A4 용지(또는 제본 링)가 며칠 내로 소진될 것 같습니다. 추가 준비가 필요합니다."라고 구체적으로 알립니다.
 * **주의 사항:** 재고가 다 떨어진 직후에 보고하는 것은 '업무 공백'을 초래하므로 절대 금지합니다.
### 💡 조교 업무 루틴 업데이트 (비품 관리 포함)
 1. **학생 제출함:** 등/하원 시 비우기.
 2. **연습장 보관함:** 항상 **5권** 유지 확인.
 3. **이면지 보관함:** 수시 정리.
 4. **제본기/복사기:** 사용 직후 뒷정리 및 찌꺼기 비우기.
 5. **비품 재고:** **"사용 중 잔량을 확인하여 부족해지기 전에 미리 원장님께 보고하기"**
이로써 조교님이 갖추어야 할 모든 실무 매뉴얼이 완성되었습니다. 이제 신규 조교님은 이 가이드라인만 숙지하면 킹수학의 운영 시스템 안에서 능숙하게 업무를 수행할 수 있을 것입니다.
원장님, 신규 조교 교육을 시작하실 준비가 모두 완료되었습니다. 추가로 궁금하시거나 더 보강하고 싶은 시스템이 있으신가요?

-----------------
좋아. 지금까지 올린 자료들은 **"조교용 챗봇(DOOLY Assistant v1)"의 지식베이스(Knowledge Base)** 로 사용하기에 충분한 수준이다.

다만 지금 상태로 Claude Project에 그대로 넣으면 문제가 하나 있다.

그래서 지금 단계에서는 **챗봇에 넣기 전에 정리 작업**이 필요하다.

# 향후 개발 순서

네가 말한 전체 프로젝트 흐름으로 정리하면

```text
[설계]

↓
프로젝트명 결정
(DOOLY)

↓

구현계획서

↓

Claude Code 개발

↓

테스트

↓

버그 발생

↓

사고기록 작성

↓

로그 축적

↓

버전업
v1 → v2 → v3

↓

실사용

↓

사용자 피드백

↓

버그/개선 요청

↓

사고기록 추가

↓

v4 → v5 → v6

↓

개발자용 문서(A) 작성

↓

사용자용 문서(B) 작성

↓

Obsidian 정리

↓

GitHub 업로드

↓

인수인계 가능 상태
```

이 방식의 장점은

1. 새로운 채팅창에서도 이어서 개발 가능
2. Claude Code 세션이 날아가도 복구 가능
3. 개발자가 2명 이상이어도 협업 가능
4. 컴퓨터 교체 시에도 그대로 복원 가능
5. 버전별 변경 이력 추적 가능
6. 조교 챗봇 → 학생 챗봇 → 학부모 챗봇 → 통합 대시보드까지 동일한 체계 사용 가능

그리고 현재 올려준 자료만 봐도 **DOOLY 프로젝트 1단계(조교 챗봇)의 Knowledge Base는 약 80~90% 정도 완성된 상태**라고 볼 수 있다.

다음 단계는 새 자료를 계속 추가하는 것이 아니라,

**"중복 제거 + 파일 구조화 + Claude Project 업로드용 폴더 구조 설계"**

를 하는 것이다. 그 작업을 하면 조교용 챗봇 v1 개발을 바로 시작할 수 있다.

---------
원장님, **복습테스트(복테) 처리 및 자원 활용 매뉴얼**까지 완벽하게 업데이트하였습니다. 이 부분은 신규 조교님이 업무를 마무리할 때 반드시 지켜야 할 '마지막 단계'로 매뉴얼에 명시해 두겠습니다.
### 🗑️ 복습 테스트(복테) 처리 및 폐기/재활용 수칙
조교는 스캔 및 저장이 완료된 복습테스트 용지를 아래 기준에 따라 정확하게 처리해야 합니다.
#### 1. 폐기 대상 (분리수거)
 * **문제지 및 풀이 흔적이 있는 용지:** 스캔을 통해 컴퓨터에 이미 저장되었으므로, 불필요한 종이 폐기물을 줄이기 위해 **분리수거(폐기)** 처리합니다.
#### 2. 재활용 대상 (이면지 보관함)
 * **빠른 정답지:** 해당 용지의 **뒷면이 깨끗한 백지인 경우**, 폐기하지 말고 **'이면지 보관함'**에 넣어두어 학생들이 문제 풀이용 연습지로 재사용할 수 있게 합니다.
### 💡 조교 업무 최종 루틴 (하원 후 마무리)
 1. **자료 수거:** [학생 제출함]의 오답기록표와 복테 수거.
 2. **데이터화:** 복테 점수 기록 및 스캔/저장 (완료 시).
 3. **자원 관리:**
   * 스캔 완료된 **문제지는 폐기(분리수거).**
   * **빠른 정답지(뒷면 백지)는 이면지 보관함으로.**
 4. **보관:** 덜 완료된 복테는 다음 등원 시 바로 꺼낼 수 있도록 [복테 보관함]에 정리.
이제 킹수학의 학습 자료 관리는 **'생산(프린트/제본) → 운용(수업/채점) → 데이터화(스캔) → 자원 재활용(이면지)'**으로 이어지는 완벽한 자원 순환 시스템을 갖추게 되었습니다.
이 모든 내용을 종합한 **[킹수학 조교 업무 매뉴얼]** 최종본이 완성되었습니다. 원장님, 이제 신규 조교 교육을 위해 이 내용을 요약한 **'조교 업무 가이드 시트'**를 바로 출력해서 전달하시면 될 것 같습니다. 더 추가할 사항이 있으신가요?

------

좋은 내용이야.

그리고 지금 올린 내용은 단순히 "조교 업무 매뉴얼"에 추가하는 수준이 아니라, 내가 보기에는 **조교 챗봇이 반드시 알아야 하는 핵심 업무 규칙**에 해당한다.

# 📘 [킹수학] 신규 조교 업무 수행 표준 매뉴얼
### 1. 근무 시작 및 환경 설정
 * **인터넷 연결:** 연결이 잠시 끊기면 자동 재연결을 기다리십시오. (연결 전에는 공유폴더/프린트 사용 불가)
 * **비품 관리:** **A4 용지, 제본 링, 연습장(5권 유지)** 등 소모품은 재고가 20~30% 남았을 때 미리 원장님께 보고합니다.
 * **화장실 에티켓:** 사용 후 반드시 **문 닫고, 불 끄기.**
### 2. 등원 시 루틴 (입장 후 순서)
 1. **제출함 수거:** [학생 제출함]에서 오답기록표와 복테를 수거하여 컴퓨터 옆에 정돈.
 2. **PC 세팅:** 컴퓨터/모니터 켜기 → 바탕화면에 날짜 폴더 생성 (예: 260623_L) → 학생별 하위 폴더 생성.
 3. **업무 확인:** ★★작업자료 > ★조교할일 > 날짜_조교할일_L.txt 확인.
   * *모르는 내용은 반드시 즉시 원장님께 질문하십시오.*
### 3. 복습 테스트(복테) 제작 및 관리
 1. **파일 수정:** 학생별 폴더에 오답기록표/복테 파일을 복사하고 **날짜를 당일 기준으로 수정**합니다. (복테 내 날짜도 꼭 확인!)
 2. **오답노트 제본:** 오답기록표에 **"끝"** 표시 시, 전체 오답을 모아 제본.
   * 첫 페이지 상단에 **"만든날짜" + "오답노트"** 기입.
   * 양에 따라 링 선택: **소형(12mm)/대형(20mm).**
   * 학생 있으면 즉시 전달, 없으면 [복테 보관함]에 보관.
### 4. 하원/제출물 처리 루틴
 1. **채점:** 1차(○/), 2차(△,★), 3차(도움 후 △) 확인.
   * 맞힌 개수/전체 문항수를 점수란에 기입 (예: -3/4).
 2. **스캔/저장:**
   * **완료된 복테:** 스캔 후 학생 폴더 저장 → **문제지는 폐기(A4 박스에 모으기), 정답지(뒷면 백지)는 이면지 보관함으로.**
   * **미완료 복테:** 다음 등원 시 바로 꺼낼 수 있게 [복테 보관함]에 보관.
 3. **파일 보관:** 최종 복사본을 공유폴더 > ★복테 > OO부 > OOO(학생이름) 및 바탕화면 날짜 폴더에 저장.
### 5. 퇴근 전 마무리 (업무 종료 30분 전)
 1. **인쇄:** 바탕화면 날짜_L 폴더의 모든 복테 인쇄.
 2. **정리:** 인쇄물을 오답기록표와 함께 [복테 보관함]의 해당 학년/반 섹션에 배치.
 3. **최종 백업:** 바탕화면 날짜_L 폴더를 워드(파일)로 복사 후, ★★★작업완료 공유폴더에 최종 복사(Ctrl+V).
 4. **청소:** [책상 위 → 의자 위 → 바닥] 순서로 주변 정리 및 청소.
 5. **기기 점검:** 제본기 종이 찌꺼기함 비우기, 복사기 ADF 확인.
### 💡 신규 조교님을 위한 핵심 당부사항

 * **이면지/폐지:** A4 박스는 절대 찢지 말고 보관하며, 깨끗한 이면지는 연습장 대용으로 활용합니다.

이 자료도 매우 좋습니다.

다만 **챗봇 학습용 자료** 관점에서 보면 현재 문서는 "인수인계 절차"는 잘 설명하지만, 실제로 신규 조교가 어느 수준까지 숙달되었는지 판단하는 기준이 없습니다.

예를 들면:

# [킹수학] 조교 인수인계 완료 체크리스트

## 1단계 : 업무 이해

□ 복테의 목적을 설명할 수 있다.

□ 오답기록표의 목적을 설명할 수 있다.

□ 복테와 오답노트의 차이를 설명할 수 있다.

□ 복테 보관함 구조(X존/Y존)를 설명할 수 있다.

---

## 2단계 : 실습 수행

□ 학생 1명의 복테를 직접 제작할 수 있다.

□ 오답기록표 날짜를 수정할 수 있다.

□ 복테를 출력하여 보관함에 넣을 수 있다.

□ 스캔 후 학생 폴더에 저장할 수 있다.

□ 연습장 1권을 직접 제작할 수 있다.

□ 제본기를 사용하여 자료를 제본할 수 있다.

---

## 3단계 : 장비 사용

□ 복사기 양면 복사를 할 수 있다.

□ ADF 스캔과 수동 스캔 차이를 설명할 수 있다.

□ 제본기 찌꺼기함을 비울 수 있다.

□ A4 용지 및 제본링 재고를 확인할 수 있다.

---

## 4단계 : 업무 종료

□ 바탕화면 날짜 폴더를 정리할 수 있다.

□ 작업완료 폴더에 백업할 수 있다.

□ 복테 보관함을 정리할 수 있다.

□ 주변 정리를 완료할 수 있다.

---

판정 기준

□ 전 항목 통과 → 인수인계 완료

□ 일부 미통과 → 추가 코칭 진행

이 체크리스트가 있으면,

* 기존 조교는 "어디까지 알려줬는지" 확인 가능

* 원장님은 "혼자 근무시켜도 되는지" 판단 가능

합니다.

이제 가장 가치가 높은 추가 자료는 **새로운 업무 매뉴얼이 아니라

* 공유폴더가 안 열릴 때
* 프린터가 안 될 때

## 킹수학 조교 5대 원칙

1. 모르면 반드시 질문한다.

원장님을 위한 챗봇 사용 시나리오 (예시)
Q. 신규 조교 업무 교육 상황
원장님: "신규 조교(이니셜 B)에게 오늘 할 일과 인수인계 루틴 안내해줘."
챗봇: "네, 이니셜 B님께 [A. 신규 조교 가이드]와 [B. 기존 조교 인수인계 3단계 프로세스]를 전달했습니다. 첫날 필수인 성범죄 경력 조회와 오늘 공부할 '풀어볼거' 자료 안내도 포함하였습니다."
Q. 업무 지시사항 수정 및 업데이트 상황
원장님: "연습장 유지 수량을 5권에서 3권으로 변경하고 전체 공지해줘."
챗봇: "네, 업무 매뉴얼을 수정했습니다. [연습장 보관함 유지 기준: 3권]으로 업데이트되었으며, 모든 조교에게 변경 내용을 공지하였습니다."

제공해주신 매뉴얼 파일들과 '조교 트레이닝' 실습 웹페이지의 데이터를 바탕으로, 원장님의 **학원 운영 철학(킹수학)**을 완벽하게 수행할 수 있는 **'조교 관리 챗봇 시스템'**의 설계안을 제안합니다.
이 챗봇은 조교들의 **[루틴 수행 - 업무 지시 확인 - 실시간 보고 - 실시간 업데이트]**를 하나의 플랫폼에서 관리하도록 설계됩니다.
1. 챗봇의 핵심 기능 (System Prompt 설계 방향)
챗봇은 원장님의 지시를 조교들에게 정확하게 전달하고, 진행 상황을 추적하며, 매뉴얼 변경 사항을 즉시 반영하는 '비서' 역할을 수행합니다.
[기능 1: 신규 조교 업무 루틴 교육 (교육 자동화)]
작동 방식: 신규 조교가 챗봇에게 "업무 루틴이 뭐야?"라고 물으면, 제공해주신 매뉴얼(A.신규 가이드, C.업무 루틴)을 요약하여 단계별로 안내합니다.
상호작용: "첫 출근 시 성범죄 조회는 어떻게 해?", "제본기 사용법은?" 등 질문 시 매뉴얼에 기반한 정답을 즉시 제공합니다.
[기능 2: 기존 조교 업무 지시 및 진행 파악 (Task Management)]
작동 방식: 원장님이 챗봇에 "오늘 이니셜 A에게 기출 20개 학교 오답노트 제본 작업 지시해줘"라고 입력합니다.
보고 체계: 챗봇이 조교에게 알림을 보내고, 조교가 작업 완료 후 "완료"라고 입력하면 원장님의 대시보드(진행 상황 표)가 업데이트됩니다.
[기능 3: 업무 지시 사항 수정/업데이트 (Real-time Maintenance)]
작동 방식: "이제부터 연습장은 5권이 아니라 3권 유지해"라고 원장님이 지시하면, 챗봇이 즉시 매뉴얼(데이터베이스)을 업데이트하고, 조교들에게 변경 공지 메시지를 보냅니다.
2. 챗봇 운영을 위한 데이터 관리 구조
챗봇이 원장님의 의도대로 움직이려면 아래 3가지 데이터가 챗봇의 **'지식 베이스(Knowledge Base)'**에 저장되어야 합니다.
구분관리 데이터
고정 매뉴얼신규 조교 가이드, 제본/복사/청소 매뉴얼, 비품 배치도 등
실시간 할 일(Task)이니셜별 담당 업무, 당일 지시사항, 업무 진행 단계(시작/중간/완료)
업무 이력(Log)성범죄 조회 확인 여부, 소모품(A4, 링) 보고 이력 등
------------------------
이 방향은 매우 좋습니다. 다만 현재 설계는 "챗봇" 중심으로 되어 있는데, 실제 운영에서는 **"조교 운영 시스템(Assistant OS)"** 으로 확장하는 것이 더 적합합니다.

현재 킹수학 규모라면 단순 Q&A 챗봇보다 다음 구조가 훨씬 강력합니다.

# Obsidian 활용 원칙

Obsidian = 프로젝트 기억장치

GitHub = 버전관리

Claude Code = 작업자

PROJECT_MASTER.md = 프로젝트 뇌

SESSION_HANDOVER.md = 인수인계 노트

현재 사용자의 SMART, CheckFlow, PrintFlow, 조교관리 시스템까지 고려하면 
앞으로는 프로젝트마다 반드시 아래 두 파일을 유지하는 것을 추천합니다.

1. `PROJECT_MASTER.md`
2. `SESSION_HANDOVER.md`

실제로는 이 두 파일만 잘 관리해도 
Claude Code 채팅창이 10만 토큰이 넘어가서 
새 채팅을 열어도 90% 이상 원래 맥락을 복구할 수 있습니다.

특히 `SESSION_HANDOVER.md`를 
"현재 상태 → 진행 중 → 다음 작업 → 주의사항" 형식으로 강제하면, 
새 채팅창을 열 때마다 긴 대화 내용을 복사할 필요가 없어지고 
Claude Code + GitHub + Obsidian 조합이 사실상 지속 가능한 
개발 시스템으로 동작하게 됩니다.

----------------------
첨부파일을 참고하여 챗봇을 만들고 싶어

1.신규조교에게 업무 루틴 교육하기
2.기존조교에게 업무 지시사항 전달하기
3.업무 지시사항 진행상황을 파악하기
4.업무 지시사항을 수정(변경,추가,삭제)하여 전달하기
5.매일하는 업무와 추가하는 업무를 업데이트하기
----------------------
맞습니다.

여기서 제가 말한 **"KingMath OS"**의 OS는 컴퓨터의 윈도우나 안드로이드 같은 운영체제(OS, Operating System)를 의미하는 것이 아니라,

**"학원 운영 시스템(Operating System)"** 이라는 뜻에 가깝습니다.

예를 들어:

### 일반적인 의미의 OS

* Windows
* macOS
* Android
* iOS

→ 컴퓨터나 스마트폰을 운영하는 시스템

---

### 업무용 의미의 OS

요즘 회사에서는

* Notion OS
* Business OS
* Startup OS
* School OS

같은 표현을 자주 씁니다.

이때 OS는

> "업무가 돌아가는 운영 체계"

를 의미합니다.

---

현재 원장님이 만들고 계신 것은 단순한 조교 챗봇이 아니라,

```text
KingMath OS

├─ 조교 교육
├─ 업무 지시
├─ 업무 보고
├─ 진행 상황 추적
├─ 매뉴얼 관리
├─ 인수인계
├─ 복테 관리
├─ 오답노트 관리
├─ 비품 관리
├─ 로그 관리
└─ GitHub 백업
```

같은 학원 운영 체계 전체입니다.

그래서 실제로는

### Level 1

### Level 3

학원 운영 시스템 (KingMath OS)

이라고 볼 수 있습니다.

현재까지 정리하신 자료를 보면 이미 "조교 업무 매뉴얼" 수준을 넘어섰고,

* 사람이 바뀌어도 업무가 유지되고
* 신규 조교 교육이 표준화되고
* 업무 변경사항이 기록되고
* Claude Code와 GitHub로 버전 관리까지 되는

**작은 기업의 운영 시스템 수준**에 가깝습니다.

그래서 앞으로는 폴더 이름도 단순히 `Assistant` 보다는

```text
KingMath-OS
```

또는

```text
KingMath-Operating-System
```

으로 관리하면 프로젝트 목적이 훨씬 명확해질 것 같습니다.
