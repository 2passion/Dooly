## Dooly란?

킹수학 학원 조교를 위한 AI 업무 도우미예요.
FAQ 검색, SOP 확인, 업무 관리를 도와줘요.

---

## 접속 방법

스마트폰 브라우저에서 아래 주소로 접속:

```
https://dooly-eight.vercel.app/06_Dooly_v1.html
```

**지원 브라우저:**
- Chrome ✅
- 삼성 브라우저 ✅
- 네이버 앱 ❌
- 카카오톡 인앱 ❌

## 자주 겪는 문제

### 문제 1: "답변을 가져올 수 없습니다"
- 원인: 인터넷 연결 불안정
- 해결: 인터넷 확인 후 다시 시도
- 또는: Mock 모드로 전환

### 문제 2: 화면이 안 보여요
- 해결: Chrome 또는 삼성 브라우저로 접속
- 네이버/카카오 인앱 브라우저 사용 금지

### 문제 3: PWA 설치 방법 (홈화면 추가)
**아이폰:**
1. Safari로 접속
2. 하단 공유 버튼 탭
3. "홈 화면에 추가" 탭

**안드로이드:**
1. Chrome으로 접속
2. 우측 상단 메뉴 탭
3. "앱 설치" 또는 "홈 화면에 추가" 탭

## 업무 관리

### 업무 상태

| 상태 | 설명 |
|------|------|
| 대기 | 아직 시작 안 함 |
| 진행중 | 현재 진행 중 |
| 완료 | 완료됨 |

### 업무 추가
1. 업무 탭 → **+ 업무 추가** 버튼
2. 업무명, 우선순위, 담당자 입력
3. 저장
