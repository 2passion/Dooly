## Dooly란?

킹수학 학원 조교를 위한 AI 업무 도우미입니다.

- 복사기, 복테, 오답노트 등 업무 질문에 바로 답변
- SOP(표준 운영 절차) 검색
- FAQ 검색
- 업무(Task) 관리

접속 주소: **https://dooly-eight.vercel.app/06_Dooly_v1.html**

# B-1. 윈도우 컴퓨터 (PC / 노트북)

## 1. 접속 방법

1. Chrome 브라우저 열기
2. 주소창에 입력:
   ```
   https://dooly-eight.vercel.app/06_Dooly_v1.html
   ```
3. Enter

## 2. 바탕화면 바로가기 만들기 (선택)

1. Chrome에서 Dooly 페이지 접속
2. 오른쪽 상단 점 3개(⋮) 클릭
3. **저장 및 공유 → 바탕화면에 바로가기 만들기** 클릭
4. 팝업에서 **만들기** 클릭
5. 바탕화면에 Dooly 아이콘 생성 완료

## 3. 사용 방법

### 질문하기 (Dooly 챗봇)
1. 하단 탭에서 **Dooly** 클릭
2. 하단 입력창에 질문 입력
3. 전송 버튼(↑) 클릭
4. 답변 확인

**예시 질문:**
- 복사기 종이 먹었어요
- 학생이 복테를 못 찾겠어요
- 오답기록표 작성 방법

### SOP 검색
1. 하단 탭에서 **SOP** 클릭
2. 검색창에 키워드 입력 (예: 복사기)
3. 해당 SOP 항목 클릭하면 내용 펼쳐짐

### FAQ 검색
1. 하단 탭에서 **FAQ** 클릭
2. 검색창에 키워드 입력
3. 해당 FAQ 항목 클릭하면 답변 확인

### 업무(Task) 관리
1. 하단 탭에서 **업무** 클릭
2. **+ 업무 추가** 버튼으로 새 업무 등록
3. 업무 상태 변경: 대기 → 진행중 → 완료

# B-2. 스마트폰 — 갤럭시 (삼성)

## 1. PWA 설치 방법 (홈 화면에 앱처럼 추가)

1. **삼성 인터넷** 또는 **Chrome** 앱 열기
2. 주소창에 입력:
   ```
   https://dooly-eight.vercel.app/06_Dooly_v1.html
   ```
3. 하단 또는 오른쪽 상단 메뉴(⋮) 탭
4. **홈 화면에 추가** 선택
5. 이름 확인 후 **추가** 탭
6. 홈 화면에 공룡 아이콘(Dooly) 생성 완료

> ⚠️ 네이버 앱이나 카카오톡 내 브라우저에서는 설치되지 않습니다.
> 반드시 삼성 인터넷 또는 Chrome 앱을 사용하세요.

## 2. 앱 실행

홈 화면의 **Dooly 공룡 아이콘** 탭

## 3. 사용 방법

### 질문하기
1. 하단 탭 **Dooly** 탭
2. 하단 입력창 탭 → 질문 입력
3. 전송(↑) 탭
4. 답변 확인 (FAQ/SOP 출처 태그도 함께 표시)

### SOP / FAQ 검색
- 하단 탭 **SOP** 또는 **FAQ** 탭
- 검색창에 키워드 입력
- 항목 탭하면 내용 펼쳐짐

### 업무 관리
- 하단 탭 **업무** 탭
- **+ 업무 추가**로 등록
- 상태 변경 가능 (다른 기기와 실시간 동기화)

## 4. 아이콘이 이상하게 보일 때

1. 홈 화면에서 Dooly 아이콘 길게 누르기
2. **삭제** 선택
3. 위 설치 방법 1~6 다시 진행

# B-3. 스마트폰 — 아이폰 (iPhone)

## 1. PWA 설치 방법 (홈 화면에 앱처럼 추가)

1. **Safari** 앱 열기 (반드시 Safari만 가능)
2. 주소창에 입력:
   ```
   https://dooly-eight.vercel.app/06_Dooly_v1.html
   ```
3. 하단 가운데 **공유 버튼** (□↑ 모양) 탭
4. 아래로 스크롤 → **홈 화면에 추가** 탭
5. 이름 확인 후 오른쪽 상단 **추가** 탭
6. 홈 화면에 공룡 아이콘(Dooly) 생성 완료

> ⚠️ Chrome, 네이버, 카카오톡 앱 내 브라우저에서는 설치되지 않습니다.
> 반드시 **Safari**를 사용하세요.

## 2. 앱 실행

홈 화면의 **Dooly 공룡 아이콘** 탭

## 3. 사용 방법

갤럭시와 동일합니다. (B-2의 사용 방법 참고)

### 질문하기
1. 하단 탭 **Dooly** 탭
2. 입력창 탭 → 질문 입력 → 전송(↑) 탭

### SOP / FAQ 검색
- 하단 탭 **SOP** 또는 **FAQ** 탭

### 업무 관리
- 하단 탭 **업무** 탭
- 갤럭시와 실시간 동기화됨

## 4. 공유 버튼이 안 보일 때

Safari 주소창을 한 번 탭하면 하단 메뉴가 나타납니다.

# 공통 — 자주 묻는 질문

**Q. 인터넷이 없어도 되나요?**
A. AI 답변(Gemini)은 인터넷 필요. SOP/FAQ 검색(Mock 모드)은 오프라인 가능.

**Q. 답변이 느려요.**
A. AI 모드는 1~5초 소요됩니다. 정상입니다.

**Q. 출처 태그(FAQ Q1, SOP 10)가 뭔가요?**
A. 답변 근거가 된 FAQ 번호와 SOP 번호입니다. 탭하면 원문 확인 가능.

**Q. 업무가 다른 사람 폰에도 보이나요?**
A. 네. Supabase 클라우드에 저장되어 모든 기기에서 실시간 동기화됩니다.

**Q. 앱이 안 열려요.**
A. 인터넷 연결 확인 후, 브라우저에서 직접 주소 입력:
https://dooly-eight.vercel.app/06_Dooly_v1.html
