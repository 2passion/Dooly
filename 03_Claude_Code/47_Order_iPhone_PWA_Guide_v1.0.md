```
# 📱 아이폰 Dooly 설치 가이드

> 아이폰에서 Dooly를 홈 화면 앱으로 설치하는 방법입니다.
> **반드시 Safari 브라우저**를 사용해야 합니다.

---

## ✅ 설치 전 확인사항

- [ ] 아이폰 iOS 16.4 이상
- [ ] Safari 브라우저 사용 (Chrome, 네이버앱 불가)
- [ ] 인터넷(와이파이 또는 LTE) 연결 상태

---

## 📋 설치 순서

### Step 1 — Safari로 접속

Safari 주소창에 아래 URL 입력:

https://2passion.github.io/Dooly/

⚠️ Chrome이나 다른 브라우저로 열면 설치 버튼이 나오지 않습니다.
반드시 Safari로 열어야 합니다.

---

### Step 2 — 공유 버튼 탭

화면 하단 가운데의 공유 버튼(□↑)을 탭합니다.

---

### Step 3 — 홈 화면에 추가

공유 메뉴에서 스크롤을 내려
"홈 화면에 추가" 를 탭합니다.

---

### Step 4 — 이름 확인 후 추가

앱 이름이 "Dooly" 로 표시되는지 확인 후
오른쪽 상단 "추가" 버튼을 탭합니다.

---

### Step 5 — 홈 화면에서 실행

홈 화면에 공룡 아이콘이 생성됩니다.
탭하면 앱처럼 실행됩니다.

---

## ❓ 자주 묻는 질문

Q. "홈 화면에 추가" 항목이 안 보여요
→ Safari로 접속했는지 확인하세요. Chrome이나 네이버 앱에서는 설치 불가합니다.

Q. 아이콘이 이상하게 보여요
→ 한 번 삭제 후 다시 설치해보세요.

Q. 앱을 열면 인터넷이 필요한가요?
→ 기본 기능(Mock 모드)은 오프라인에서도 사용 가능합니다.
→ 단, 최초 설치 시에는 인터넷 연결이 필요합니다.

Q. 안드로이드는요?
→ 갤럭시 S25는 이미 설치 완료되었습니다.
→ Chrome 브라우저 → 주소창 옆 메뉴 → "앱 설치" 또는 "홈 화면에 추가"

---

## 📞 문제 발생 시

설치가 안 될 경우 원장님께 문의하세요.
```
